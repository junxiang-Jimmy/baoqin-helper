# 报寝助手 · 安卓 App 使用说明

一个装在安卓手机上的小工具，替你完成 baoqin.yeer.tech 的每日报寝：

- **一键报寝**：点一下 App 图标 → 自动读取本班状态 → 把「实到」填成 25 → 等同于点网页上的「保存修改」→ 屏幕直接显示成功/失败。
- **定时报寝**：设置里开启后，每天到点（默认 **21:15**，报寝窗口 21:10 开放）由系统闹钟自动完成报寝，并推送结果通知；如果当时没开放或网络不好，每隔 5 分钟自动重试（最多 8 次）；手机重启后闹钟自动恢复。

默认配置已经写好：**人工智能2404班（class-14）· 实到 25 人**，装上就能用；换班级/人数在 App「设置」里改即可。

---

## 一、安装

1. 把 `BaoqinHelper-debug.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘都可以）。
2. 手机上点开安装。系统会提示「未知来源应用」，选择**仍要安装 / 允许**（不同手机叫法不同）。
3. 打开 App 即完成第一次报寝。

> 这个 APK 是 debug 签名的自用工具，不会上架商店，仅你自己安装使用。

## 二、首次配置（推荐 1 分钟做完）

打开 App → 点「设置」：

1. **① 通知权限**：允许接收「报寝成功/失败」通知（安卓 13+ 需要）。
2. **② 精确闹钟权限**：允许「闹钟和提醒」，保证 21:15 准点执行（安卓 12+ 出现）。
3. **③ 忽略电池优化**：选「允许」，防止被系统在后台清理。
4. 打开 **每天定时报寝** 开关，时间默认 21:15（可点按钮改），点「保存设置」。

设置页下方会显示「下一次自动报寝：xx月xx日 21:15」。

## 三、两种用法

| 用法 | 操作 | 适合 |
| --- | --- | --- |
| 手动一键 | 需要报寝时点一下 App 图标 | 偶尔想自己控制 |
| 全自动 | 设置里开启定时，之后什么都不用做 | 日常（推荐） |

两种方式提交的内容相同，全部来自「设置」页：

- **专业班级**（必填）、**实到人数**（必填，默认 25）
- **未到分类人数**（选填）：外宿、请假、休学、离校、其他未到，不填按 0 提交
- **请假、外宿及备注**（选填）：不填则提交空备注
- **假条照片/辅导员同意截图**：本 App 不提交，需要时用网页版

校验规则与网页一致：实到 + 各未到项之和必须等于应到人数，保存设置时会提前核对，提交时服务器再校验一次。已提交过再点一次，效果等同网页上的「保存修改」。

## 四、国产手机后台限制（重要）

各厂商系统会清理后台应用，请按自己的品牌设置一次：

- **小米 / 红米（MIUI、澎湃 OS）**：设置 → 应用设置 → 应用管理 → 报寝助手 → 自启动 **开**；省电策略改为**无限制**。
- **华为 / 荣耀（HarmonyOS、EMUI）**：设置 → 应用 → 应用启动管理 → 报寝助手 → 改为**手动管理**，允许自启动、关联启动、后台活动。
- **OPPO / 一加（ColorOS）**：设置 → 应用 → 报寝助手 → 允许**自启动**，电池优化改为**不优化**。
- **vivo / iQOO（OriginOS）**：设置 → 应用 → 报寝助手 → 允许**自启动**；电池里开启**后台高耗电**。
- **三星**：设置 → 电池 → 后台使用限制 → 把报寝助手从「深度睡眠」排除。
- **原生安卓（Pixel 等）**：完成设置页三个权限按钮即可。

## 五、常见问题

- **提示「今天的报寝 21:10 才开放」**：窗口还没开。手动模式点「再报一次」即可；定时模式会自己重试，不用管。
- **提示「已截止 / 已被管理员审核锁定」**：过了 23:50 或宿管已审核锁定，只能找管理员更正。
- **提示「应到 xx 人，但实到 x + 未到 x = x，对不上」**：实到+未到必须等于应到。到设置里调整实到或未到人数；班级人数变了就按新的应到数改。
- **定时没执行**：检查第四节的品牌设置；确认「设置」里定时开关是开的；通知栏搜「报寝」看是否有失败/重试通知。
- **有同学临时请假/外宿**：打开「设置」把未到分类人数和备注填好、保存即可（一键和自动报寝都会照此提交）；恢复后记得改回 0。
- **换手机**：新手机装 APK 后重新进「设置」保存一次即可（闹钟存在本机系统里）。

## 六、说明

- App 只会向 `https://baoqin.yeer.tech` 发请求（可在设置里改），不需要任何账号密码，与网页端同样免登录。
- 报寝是集体信息，请确保「设置」里的人数与备注符合当天实际情况，缺勤请在设置里如实填写未到分类。
- 接口行为以网页版为准：如果网站将来改版（字段、校验变化），App 需要更新。

## 七、给开发者的信息

- 工程：`BaoqinApp/`（Kotlin + AGP 8.5.2 + Gradle 8.9，minSdk 26 / targetSdk 34，**零第三方依赖**，通知与 HTTP 全用系统 API）。
- 接口：`GET /api/classes`、`GET /api/report?class_id=…&cohort=…`、`PUT /api/report`（JSON 字段固定：class_id, day, expected, present, off_campus, leave, suspended, departed, other, note；校验「实到+未到=应到」）。
- 本地构建：
  ```
  cd BaoqinApp
  gradle assembleDebug        # 产物 app/build/outputs/apk/debug/app-debug.apk
  ```
- 无电脑也可构建：把 `BaoqinApp/` 推到 GitHub 仓库（含 `.github/workflows/build-apk.yml`），Actions 会自动编译并产出 APK 工件。
- 源码结构：
  - `ReportEngine.kt` 接口引擎（读状态/提交/错误翻译）
  - `MainActivity.kt` 打开即报寝的主页
  - `SettingsActivity.kt` 设置页（班级/人数/定时/权限）
  - `AlarmScheduler.kt` `AlarmReceiver.kt` `BootReceiver.kt` `ReportService.kt` 定时调度与前台服务
  - `Prefs.kt` 本地配置
